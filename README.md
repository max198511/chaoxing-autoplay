# 学习通视频自动播放助手

一个基于 Tampermonkey（油猴）的浏览器自动化用户脚本，用于超星学习通视频的自动播放、自动续播与播放卡顿恢复。

## ⚠️ 免责声明

本项目仅用于**浏览器自动化技术学习与研究**，展示油猴脚本的 DOM 操作、事件监听、定时轮询等技术。

**请勿将本脚本用于实际刷课 / 刷学习时长**。自动刷课时违反学习通（超星）的用户协议，也可能违反学校关于学术诚信的规定。使用者应自行承担由此产生的一切后果，本项目不鼓励、不负责任何违规使用。

## 功能

- 自动播放页面中的视频（含 iframe 内嵌视频）
- 视频播放结束后自动切换到下一节
- 检测播放卡顿并自动恢复（重播 / 跳过 / 刷新）
- 自动点击"继续观看"等弹窗

## 技术要点

- 遍历 iframe 内的 DOM（`allDocs` 递归收集 iframe 文档）
- 通过 `querySelectorAll('video')` 定位视频元素并接管播放
- 用 `setInterval` 定时轮询，结合进度对比实现卡死检测与分级恢复
- `WeakSet` 防止重复接管同一个视频节点

## 安装

1. 浏览器安装 Tampermonkey / Violentmonkey 扩展
2. 新建用户脚本，粘贴本脚本内容
3. 打开学习通视频页面，脚本自动运行
